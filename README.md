# Kyng, developer portfolio

Single-page portfolio. React 19, Vite 8, TypeScript, Tailwind 4, Three.js, Framer Motion. No runtime network dependencies (fonts are bundled).

```bash
npm ci
npm run dev       # local dev
npm run build     # type-check + production build into dist/
npm run preview
```

Requires Node 22. Placeholder links (live sites, Notion pages, social profiles, email) live in `src/data/projects.ts` and `src/components/Rest.tsx`.
